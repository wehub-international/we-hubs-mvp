# WE HUBS Brand Assets

## Brand Palette
- Navy: #0F1D33
- Brass / Gold: #C89B3C
- White: #FFFFFF

## Companies
### WE STUDY ACADEMY
- Purpose: Education / language learning
- Tone: trustworthy, academic, premium
- Recommended accent: navy + brass
- Use case: academy dashboard, learning modules, student portal

### WE STUDY
- Purpose: study abroad / admissions
- Tone: professional, analytical, conversion-focused
- Recommended accent: navy + brass
- Use case: admissions CRM, case management, pipeline dashboards

### WE TRAVEL
- Purpose: study tours / educational travel
- Tone: energetic, adventurous, premium
- Recommended accent: navy + brass + warm neutral
- Use case: travel itinerary, booking, traveler cards

## Brand Rules
- Use navy as dominant base
- Use brass as highlight / CTA / premium accent
- Use white for clean backgrounds
- Maintain consistent spacing and typography
- Keep brand assets on transparent backgrounds
